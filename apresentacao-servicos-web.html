9.1 · Introdução

O que é um serviço web

É um programa que oferece operações pela internet para que outros programas as chamem. A conversa usa HTTP, as mensagens seguem um formato padrão e cada serviço tem um endereço (URI).

Site web · para pessoas

GET /imoveis/rlx-001

← 200 text/html
<h1>Casa em Porto Alegre</h1>
<img src="sala.jpg"> …

Devolve uma página pronta para alguém ler. Mudar o layout não quebra ninguém.

Serviço web · para programas

GET /virtual-tours/rlx-001

← 200 application/json
{ "id": "rlx-001", "status": "PUBLISHED",
  "panoramas": [ … ] }

Devolve dados estruturados que o programa cliente usa. O formato é um contrato: mudar quebra o cliente.

HTTP

Transporte comum a qualquer linguagem.

Formato padrão

XML no livro, JSON no projeto.

URI

Endereço de cada serviço ou recurso.

Descrição

Documento que diz como chamar (WSDL, Swagger).

No Inner View, a API NestJS é o serviço web e o app Ionic é o programa cliente. O app também consome um serviço web de terceiros, o ViaCEP.

9.2 · Quadro REST · Fielding, 2000

O padrão REST

REST (Representational State Transfer) é um estilo de arquitetura descrito por Roy Fielding, um dos autores do HTTP. A ideia: em vez de chamar funções remotas, o cliente manipula recursos com as operações que o próprio HTTP já oferece.

1. Recursos com URI

Tudo que o sistema expõe é um recurso com endereço próprio.

/properties/:id · /virtual-tours/:id

2. Interface uniforme

Poucas operações, iguais para todos os recursos: os verbos HTTP.

GET lê · POST cria · PATCH altera · DELETE remove

3. Representações

O cliente recebe uma cópia do estado do recurso num formato.

Tour em JSON, thumbnail em image/jpeg.

4. Sem estado

Cada requisição traz tudo o que o servidor precisa. Nada fica guardado na memória da API.

O JWT vai em todo Authorization: Bearer.

5. Cache

Respostas podem dizer se podem ser reaproveitadas.

Thumbnail: Cache-Control: public, max-age=3600.

6. Cliente-servidor em camadas

Cliente e servidor evoluem separados, e no meio pode haver proxies.

App Ionic → proxy /api → API → PostgreSQL.

9.3 · Descrição de serviço

WSDL no livro, Swagger no projeto

O que é WSDL

A Web Services Description Language é um documento XML que descreve um serviço web, como uma IDL. Com ela, um programa sabe como chamar o serviço sem ver o código do servidor e pode até gerar o cliente automaticamente.

  • types: formato dos dados das mensagens
  • interface: as operações oferecidas
  • binding: protocolo e formato usados (SOAP, HTTP)
  • service: o endereço (URI) onde o serviço está

9.5 · Segurança

Segurança

O que o capítulo diz

O TLS protege só o canal, de ponta a ponta. Como uma mensagem de serviço web pode passar por intermediários, o livro apresenta a segurança XML: a XML Signature assina partes da mensagem (garante autoria e que nada foi alterado) e a XML Encryption cifra só as partes sigilosas. A proteção viaja junto com o documento.

Canal

HTTPS (TLS) em produção, com HSTS obrigando o navegador a nunca usar HTTP.

Token assinado

O JWT é assinado pela API e conferido a cada requisição. Se alguém mudar o conteúdo, a assinatura não bate, como na XML Signature.

Permissão

Guards por papel: só admin vê usuários e analytics. Cada imobiliária só acessa os próprios dados.

Sessão revogável

Access token dura 1 dia, refresh dura 7. O refresh só vale se a sessão existe no banco, guardada como hash bcrypt.

Mensagens validadas

Todo corpo passa pelo schema Zod antes da regra de negócio. Mensagem malformada volta 400.

Token não vaza

O interceptor não envia o JWT para serviços externos: a chamada ao ViaCEP sai sem credencial.

Não usamos cifra de partes da mensagem (XML Encryption): a comunicação é direta entre cliente e API, sem intermediários, e o TLS já cifra a mensagem inteira.

Fechamento · Serviços web e o Inner View

O Inner View é um serviço web REST

O Inner View é um sistema de tour virtual de imóveis. O corretor envia fotos 360° de cada cômodo e liga um cômodo ao outro por pontos clicáveis (hotspots). O visitante abre o link e anda pelo imóvel no navegador.

  • Dados · :5432PostgreSQL + PrismaImobiliárias, imóveis, tours, panoramas
